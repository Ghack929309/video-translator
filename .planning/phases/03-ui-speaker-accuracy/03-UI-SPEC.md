## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps inside Select/Dropdown items, inline padding |
| sm | 8px | Spacing between Label and Select trigger |
| md | 16px | Default gap between form fields (e.g. Engine row vs Language row) |
| lg | 24px | Section padding (e.g. Card content padding) |
| xl | 32px | Layout gaps between top-level layout components |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions: 
- `px-3 py-2` (12px/8px) used for Shadcn `SelectTrigger` to match radix-nova specs.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | hsl(var(--background)) | Main app background, Card surfaces (dark mode default) |
| Secondary (30%) | hsl(var(--muted)) | Muted text, disabled form elements, Select dropdown backgrounds |
| Accent (10%) | hsl(262 83% 58%) | Primary CTA backgrounds, active RadioGroup/Select border |
| Destructive | hsl(var(--destructive)) | Error states, validation failures |

Accent reserved for: 
- The "Translate" or "Start Job" Primary CTA.
- The active border indicator on the currently selected TTS engine or Dropdown focus state.
